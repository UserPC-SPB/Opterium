# any_tool

Утилита для **быстрого** извлечения данных. См. [документацию](https://example.org/docs "Docs").

![Логотип](logo.png)

## Установка

1. Скачайте архив
2. Распакуйте:
   - `bin/` — исполняемые файлы
   - `docs/`
3. Запустите `any_tool --help`

- [x] Windows
- [ ] Linux

## Пример

```bash
any_tool -i logs/ -t tpl.yml \
  -o out.md
```
