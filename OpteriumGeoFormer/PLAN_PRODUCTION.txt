## ПРОБЛЕМА ТЕКУЩЕЙ ВЕРСИИ
- Python прототипы (медленные)
- Нет полной интеграции модулей
- GenerativeCube — только Python
- Нет Rust native для 3D куба
- Нет E8 attention в pipeline
- Нет Soul/RubikSoul в GeoFormer

## ЦЕЛЬ
Полноценный движок на Rust с Python bindings:
- GenerativeCube (3D) — native Rust
- Интеграция с GeoFormer таблицами
- E8 attention в pipeline
- RubikSoul (bias) в attention
- Morpho-связи (живые, усиливаются)
- Полные тесты (100+)

# ═══════════════════════════════════════════════════════════════
# ЧАСТЬ 1: GENERATIVE CUBE — RUST NATIVE
# ═══════════════════════════════════════════════════════════════

## 1.1 cube.rs — Генеративный 3D куб
- CubeNode: x, y, z, V, S, C, D_body, phase, disc
- GenerativeCube: кэш, bucket index, morpho
- O(1) генерация узла по адресу
- Bucket spatial index для соседей

## 1.2 C API — geofield_cube_*
- geofield_cube_get_node(x, y, z) → CubeNode
- geofield_cube_get_neighbors(x, y, z, radius) → список
- geofield_cube_tension(a, b) → int
- geofield_cube_analogy(A, B, C) → D
- geofield_cube_morpho_link(src, tgt, weight)
- geofield_cube_stats() → JSON

## 1.3 Python bindings
- CubeNode class
- GenerativeCube class
- Все методы через CFFI

## 1.4 Тесты
- 20+ тестов (генерация, соседи, tension, analogy, morpho, stats)

# ═══════════════════════════════════════════════════════════════
# ЧАСТЬ 2: ИНТЕГРАЦИЯ С GEOFORMER
# ═══════════════════════════════════════════════════════════════

## 2.1 CubeNode → GeoFormer Cell
- 3D адрес → 2D проекция (S, D)
- V, S, C → P, S, D маппинг
- Дискриминант → верификация

## 2.2 E8 Attention + Cube
- E8 roots из 3D адреса (x,y,z) → 8D root
- Attention weights через E8 dot products
- RubikSoul bias в attention

## 2.3 Pipeline с кубом
- Encoder: token → 3D адрес
- Navigation: куб + GeoFormer таблицы
- Decoder: 3D адрес → token

- geofield_soul_signature(soul) → int
- geofield_soul_displacement(soul) → int

## 3.3 Python bindings
- RubikSoul class
- Все методы через CFFI

# ЧАСТЬ 5: ПОЛНЫЙ PIPELINE
# ═══════════════════════════════════════════════════════════════

## 5.1 Полный pipeline
- Encoder: token → 3D адрес (обучаемый)
- Cube Navigation: 3D куб + GeoFormer таблицы
- E8 Attention: attention weights через E8
- RubikSoul: bias в attention
- Morpho: живые связи
- Decoder: 3D адрес → token (обучаемый)

## 5.2 Тесты
- 100+ тестов
- Интеграционные тесты
- Бенчмарки

## 6.1 Бенчмарки
